\section{Standard DS: rotation of the circle}

    $T^1$ is the 1D torus, which is defined as the interval $[0,1]$ where 0 is identified as 1 and vice versa. This definition is a bit heuristic, though. \end{definition}

Consider $T=R_{\alpha}:T^1\rightarrow T^1, x \rightarrow x+\alpha \mod 1$ where $\alpha\in\mathbb{R}$ is a parameter, which is equivalently represented by $x\in[0, 1)\rightarrow \{x+\alpha\}$ where the curly braces indicate the fractional part.

This is the same as doing 0 to $2\pi$ in a circle. Notice that it's invertible with the inverse $R^{-1}_{\alpha}:T^1\rightarrow T^1,\,x\rightarrow x-\alpha$.

\begin{observation}
    $O(x_0)=\{R_{\alpha}^n(x_0)\}_{n\in\mathbb{Z}}$ with $R^n_{\alpha}(x_0)=x+n\alpha mod 1$ 
    Notice how this is not exactly the same as the definition, because we are truncating the integer just at the end instead of at every iteration. This may be important when dealing with computer programs, since you may want to perform the mod 1 operation just at the very end.
\end{observation}

We are now ready to make some observation about the nature of this kind of movement on the toroidal space.

\begin{proposition}
    If $\alpha=\frac{p}{q}$, $p, q\in\mathbb{Z},\, \{p, q\}=0$, all orbits are periodic with a fundamental period (i.e. the smallest of all possible periods) of $q$.
\end{proposition}
\begin{proof}
    \begin{equation*}
        R_{\alpha}^n(x)=x+n\alpha \mod 1=x+n\frac{p}{q} \mod 1
    \end{equation*}
    We want to prove that $x\in Fix(R_{\alpha}^n)$ for some $n$, which is the definition of a periodic point, and the minimum $n$ for which it is true is $q$.
    So, we first show that $q$ is indeed a period:
    \begin{equation}
        R_{\alpha}^q(x)=x+q\frac{p}{q} \mod 1=x+p \mod 1=x
    \end{equation}
    because mod 1 truncates the integer, and $p\in\mathbb{Z}$. The fact that it is the minimum period is trivially determined by the fact that $\{p,q\}$.\footnote{Different from what the professor did.}
\end{proof}

\begin{proposition}
    If $\alpha\in\mathbb{I}=\{x|x\in\mathbb{R} \land x\notin\mathbb{Q}\}$\footnote{So, irrational numbers.} then the orbit $O(x)$ is dense in $T^1$ $\forall x\in T^1$
\end{proposition}
\begin{proof}
    We begin by proving that the cardinality of $O(x)=\{R_{\alpha}^n(x)\}_{n\in\mathbb{Z}}$ is $\infty$, which is demonstrated when we prove that $\alpha \in \mathbb{I}$ implies no fixed points. Proven by contradiction:
    \begin{align*}
        x\in Fix(R^n_{\alpha})\iff x+n\alpha \mod 1=x \mod 1\iff \\
        n\alpha  \mod 1 =0\iff n\alpha\in\mathbb{Z}\iff\alpha\in\mathbb{Q}
    \end{align*}

    Since, by hypothesis, $\alpha\notin\mathbb{Q}$, then $\forall x\in T^1, x\notin Fix(R^n_\alpha)$, which, in turn, implies $\#O(x)=\infty\,\forall x\in T^1$. Since $T^1$ is compact, by Bolzano-Weirstrass's theorem we can say that $O(x)$ has an accumulation point, i.e. a point whose neighbourhoods always contain at least another point in the set. 

    So, by definition:
    \begin{equation*}
        \forall \epsilon>0 \exists m,n\in\mathbb{Z}(m>n) \text{ such that } d(R_{\alpha}^n,R_{\alpha}^m)<\epsilon
    \end{equation*}
    
    Now, if we accept as true that all rotations conserve the distance: \begin{equation*}
        d(R_{\beta}(y), R_{\beta}(x))=d(x,y)\forall\beta\in\mathbb{R}
    \end{equation*}
    we may apply such property to the aforementioned points:
    \begin{equation*}
        d(R_{-n\alpha}(R_{\alpha}^m), R_{-n\alpha}(R_{\alpha}^n))=d(R^{m-n}_{\alpha}(x), x)<\epsilon
    \end{equation*}
    
    m and n though are arbitrary, so if we call $k=m-n$ we just proved that $R^k_{\alpha}(x)$ is dense in $T^1$, which implies that the same is true for $O^1$.
\end{proof}

We can deal with a fun application of this fact, but before we need a lemma.

\begin{lemma}
    $\log_{10}2\notin\mathbb{Q}$
\end{lemma}
\begin{proof}
    RAA If the statement is false, then $\log_{10}2\in\mathbb{Q}$, which implies the following: \begin{equation*}
        \exists p,q\in\mathbb{N}\text{ such that }10^{p/q}=2\iff 10^p=2^q
    \end{equation*}. 
    That, though is impossible because powers of 2 never end with 0. 
    
    Alternatively, to convince us forther, we can separate $10^p=2^p5^p$, which implies $2^p5^p=2^q$, but this is only possible if p and q are 0, which does not make sense.
\end{proof}

\begin{proposition}
    If $r\in\mathbb{Z}^+$ there exists an n such that the decimal representation of $2^n$ starts with the digits of r
\end{proposition}
\begin{proof} \footnote{Last part is different from the professor's, check for accuracy.}
    Consider $R_{\alpha}: T^1\rightarrow T^1$, $\alpha=\log_{10}2\notin \mathbb{Q}$

    We now notice that $\forall n\in\mathbb{N}$ we can write (uniquely) $2^n=10^{k_n}q_n$, with $k_n\in\mathbb{N}$ and $q_n\in[1,10)$. We also notice that: \begin{equation*}
        \log_{10}(2^n)\mod 1=n\log_{10}(2)\mod 1=n\alpha=R_{\alpha}^n(0) \mod 1
    \end{equation*}
    and, at the same time: \begin{align*}
        log_{10}(2^n) \mod 1=k_n+log(q_n) \mod 1&=log(q_n) \mod 1 \\\Rightarrow \{log(q_n)\}_{n\in\mathbb{N}}&=\{R_{\alpha}^n(0)\}_{n\in\mathbb{N}}
    \end{align*}
    Thus putting the problem on the torus. This implies, because of the last results, that $\{\log_{10}q_n\}$ is dense in $T^1$, which in turn implies that $\{q_n\}_{n\in\mathbb{N}}$ is dense in [1, 10), as shown in \autoref{fig:density_exp}. We may now end the proof by realizing that: \begin{align*}
        A_r&=\{y\in[1, 10)| \text{the decimal representative of y starts with the digits of r}\} \\
        &=\left[\frac{r}{10^{d-1}}, \frac{r+1}{10^{d-1}}\right),\, r\in [10^{d-1}, 10^d]
    \end{align*}
    So the numbers we are looking for are an interval for any $r$. Because of the definition of density, there are infinitely many points in $A_r\cap\{q_n\}_{n\in\mathbb{N}}$ for any $r$.

\subsection{Topological dynamics}
For now on, M is a topological space.
\begin{definition}
    A topological space is a space $M$ which has a topology. A topology over $M$ is a set of subsets $\tau$, called open sets, which have the following properties: \begin{itemize}
        \item $\emptyset$ and $M$ are in $\tau$;
        \item an arbitrary (infinite or finite) union of sets in $\tau$ belong to $\tau$;
        \item The intersection of any finite number of members of $\tau$ belongs to $\tau$.
    \end{itemize}
\end{definition}

We shall now define the concept of topologically transitive.

\begin{definition}
    $(M, \phi^t)$ is called topologically transitive if $\forall U, V$ nonempty open sets there exists some $t(U, V)\in\mathbb{G}$(i.e. $\mathbb{N, Z, R}_0^+, \mathbb{R}$) such that $\phi^t(U)\cap V\neq \emptyset$. We are assuming t is in $\mathbb{R}, \mathbb{R}_0^+, \mathbb{Z},\mathbb{N}$.
\end{definition}

In practice, what happens is what is shown in \autoref{fig:top_transitivity}.

Notice that this is a form of chaoticity.

\begin{definition}
    A locally compact separable metric space is a metric space(i.e. a set where a distance is defined) which is locally compact, which means that the closure of every ball is compact, and separable, which means that there exists a set of open sets $\{U_k\}_{k\in\mathbb{N}}$ that is a countable basis of the topology, i.e. $\forall U$ open $\exists k|U_k\subseteq U$. Reminder that open sets, in this context, are all sets with the property: \begin{equation*}
    \forall x\in A \exists \rho>0|B_{\rho}(x)\subseteq A
    \end{equation*}
\end{definition}

\begin{proposition}
    Let M be a locally compact separable metric space\footnote{A good space.}, and $T:M\rightarrow M$ continuous. Then,  $(M, T)$ is topologically transitive $\iff$ there exists $x\in M$ such that $O(x)$ is dense.
\end{proposition}
\begin{proof}
    Let's prove $\Leftarrow$.

    Let's take $\{T^n(x)\}$, which is dense by hypothesis. This implies there exists $k,m (m>k)$ such that $T^k(x)\in U, T^m(x)\in V$\footnote{Notice that we may take $m>k$ as a hypothesis because, since the orbit is dense and the space is good, it covers the whole space an infinite number of times. This implies that I can decide which index is greater without problems.}. 
    So, we may write: \begin{equation*}
        T^m(x)=T^{m-k}(T^k(x))
    \end{equation*}
    And then notice that: \begin{equation*}
        T^{m-k}(T^k(x))\in T^{m-k}(U)\cap V \Rightarrow T^{m-k}(U)\cap V\neq \emptyset
    \end{equation*}
    because $T^{m-k}(T^k(x))$ is at least one point. So, $m-k$ is the $t(U, V)$ in the definition.

    We are going to prove that there is an orbit that visits all open sets in the countable basis. 

    Take $\{U_k\}$ countable basis of the topology. Since T is topologically transitive, we know that there exists $n_0\in\mathbb{Z}$ such that $T^{n_0}U_0\cap U_1\neq \emptyset$, which implies that $U_0\cap T^{-n_0}U_1\neq \emptyset$, due to the fact that, for any function, the counter-image of an interception is the interception of the counter-images. So, if the first interception is not empty then the counter-image of the interceptions is not empty. 

    Due to the openness of said interception (which is a direct consequence of the continuity of T), we may find some $V_1$, included in its closure $\bar{V_1}$ (assume it is compact), for which: \begin{equation*}
        V_1\subset\bar{V_1}\subset U_0\cap T^{-n_0}U_1
    \end{equation*}
    The point is that the interception is not empty, and it contains more than one point. 
    
    By using again the definition of topologically transitive, we may also say that \begin{equation*}
        \exists n_1 | T^{n_1}V_1\cap U_2\neq\emptyset\Rightarrow V_1\cap T^{-n_1}U_2\neq\emptyset,\,\text{open}
    \end{equation*}
    Which, again, implies that there exists some $V_2\subset\bar{V_2}\subset V_1\cap T^{-n_1}U_2$. We may repeat this process (as shown in \autoref{fig:nested}) for the whole basis:
    \begin{equation*}
        \exists V_k\subset\bar{V_k}\subset V_{k-1}\cap T^{-n_{k-1}}U_k
    \end{equation*}
    So you can say that $V=\cap_{k\in\mathbb{N}}V_k=\cap_{k\in\mathbb{N}}\bar{V_k}$, where the equality stems from the fact that the basis is infinite. By a property of locally compact separable metric spaces, closed sets cannot be empty, so $V\neq\emptyset\Rightarrow\exists x\in V$.

    For every $k\in\mathbb{N},\,x\in T^{-n_{k-1}}U_k\Leftrightarrow T^{n_{k-1}}(x)\in U_k$. So O(x) intercepts all elements of the countable basis, which means that it visits all open sets. 
\end{proof}

\begin{definition}
    Within the above general framework, if we take a dynamical system over a phase space $(M,\phi^t)$, $\phi^t$ is called minimal if all orbits are dense.
\end{definition}

An example of an easy map is the discrete translations of the torus. Take $M=[0, 1)^d\approxeq T^d$(the torus). The discrete translations are defined as $T_{\gamma}:T^d\rightarrow T^d, \gamma\in\mathbb{R}^d,$ where $ T_{\gamma}=x+\gamma \mod \mathbb{Z}^d=T_{\gamma}(x_1,..,x_d)=(x_1+\gamma_1 \mod 1,..,x_d+\gamma_d \mod 1)$. Notice that we are now dealing with the generalization of the rotation. The whole thing is shown in \autoref{fig:torus_translation}.

\begin{definition}
    A set $A$ is called T-invariant if and only if $T^{-1}A=A$. A function f is called T-invariant if $f:M\rightarrow\mathbb{R}\iff f=f\circ T$. This kind of functions are oftentimes also called observables. 
\end{definition}

\begin{definition}
    For a set $A$, $1_A$ is called the indicator and is defined as \begin{equation*}
    1_A(x)=\begin{cases}
                1,\, x\in A \\
                0,\, x\notin A
            \end{cases}
    \end{equation*}
\end{definition}

\begin{proposition}
    $A$ is invariant $\iff 1_A$ is invariant.
\end{proposition}

\begin{proof}
    $A$ invariant means that $A=T^{-1}A$, which implies that $1_A=1_{T^{-1}A}$. Now, notice that $1_A\circ T=1_A(T(x))$, which is exactly the same as saying $1_A\circ T=1_{T^{-1}A}$ because $T(x)\in A \iff x\in T^{-1}A$. Since all the passages are if and only ifs, the proposition if proven.
\end{proof}  

\begin{proposition}
    Be M a locally compact separable metric space, then \begin{align*}
        \text{(M, T) is topologically transitive} \Rightarrow & \nexists f:M\rightarrow \mathbb{R}\text{ continuous,} \\&\text{T-invariant and non-constant.}
    \end{align*}
\end{proposition}
\begin{proof}
    We proved that (M, T) topologically transitive implies the existence of a point $x_0$ for which the orbit $O(x_0)$ is dense. Density implies that for every $x\in M$ there exists a sequence $y_i\subset O(x_0),\, y_i=T^{m_i}x_0$ such that $y_j\rightarrow x$ for $j\rightarrow\infty$. If we assume the existence of a continuous f, we may find that $f(y_j)\rightarrow f(x)$ for $j\rightarrow\infty$. Assuming that said f is also T-invariant, you get that $f(y_j)=f(T^{m_j}(x_0))=f(x_0)$. This implies that the aforementioned limit becomes an equality, because $f(y_j)$ is constant. 
    
    Concatenating the equalities, we get that  $\forall x\in M,\, f(x)=f(x_0)$. So, $f(x)$ is constant, which confirms the thesis since there is no f that satisfies all three of the conditions.
\end{proof}

\begin{lemma}
    Be M  a locally compact separable metric space, T a homeomorfism, then \begin{equation*}
        \text{T is topologically transitive} \iff \nexists U, V\neq\emptyset\text{, open, disjoint and T-invariant.}
    \end{equation*} 
\end{lemma}

\begin{proof}
    $\Rightarrow$ is easy. 
    
    RAA. Assume there exists $U, V$ non-empty, open, disjoint and T-invariant. If T is topologically transitive, then $T^{n}U\cap V\neq\emptyset$ for some n.
    
    Since $T^nU=U$ because they are T-invariant, so $U\cap V\neq\emptyset$, but we assumed that they were indeed disjoint.

    $\Leftarrow$ is proven, again, by contradiction. 
    
    RAA Suppose T is not topologically transitive. 
    
    So, $\exists U_0, V_0$ open, non-empty sets such that $T^nU_0\cap V_0 = \emptyset \forall n\in \mathbb{Z}$\footnote{They are also disjoint, since n=0 is included and $T^0(U)=U$.}, which is simply the negation of the definition. 
    
    We then set $U=\cup_{n\in\mathbb{Z}}T^nU_0; V=\cup_{n\in\mathbb{Z}}T^{n}V_0$. U and V are obviously non-empty, they are open because of the fact that T is a homeomorphism and T-invariant as we are considering all $n\in\mathbb{Z}$.
    
    But they are also disjoint: if they were not, considering the way they are built, $T^mU_0 \cap T^kV_0\neq\emptyset$ for some m and k. Considering the fact that T is a homeomorphism, this implies that $T^{m-k}U_0\cap V_0\neq \emptyset$, which would negate the very first building block of this proof. So, U and V are non-empty, open, disjoint and T-invariant, which is a contradiction to our hypothesis.
\end{proof}

\begin{definition}
    A vector is said to be rationally independent if is linearly independent on the field of rational numbers (i.e. there does not exist a vector $(r_0,...,r_d)\in\mathbb{Q}^{d+1}\setminus \{0\}$ such that $r_01+r_1\gamma_1+...+r_d\gamma_d=0$).
\end{definition}

\begin{proposition}
    A vector $(1, \gamma_1,...,\gamma_d)$ is rationally independent $\underset{1}{\iff}$ there does not exist a vector $(r_0,...,r_d)\in\mathbb{Z}^{d+1}\setminus \{0\}$ such that $r_01+r_1\gamma_1+...+r_d\gamma_d=0$ $\underset{2}{\iff} k_1\gamma_1+...\notin\mathbb{Z}$ for every combination of $k_d$\footnote{https://www.youtube.com/watch?v=ZeOmeOhToiw}.
\end{proposition}

\begin{proof}
    We shall start by proving $\underset{1}{\iff}$. 
    
    $\Rightarrow$ is trivial, since is such a vector does not exist in the set of rationals, it cannot exist in the set of integer numbers.

    $\Leftarrow$ is a bit harder but still simple. 
    
    RAA if there was indeed a rational vector $(r_0,...,r_d)\in\mathbb{Q}^{d+1}\setminus \{0\}$ such that $r_01+r_1\gamma_1+...+r_d\gamma_d=0$, then we could say $r_i=\frac{p_i}{q_i},\, p_i \in \mathbb{Z}, q_i\in\mathbb{Z}\setminus\{0\}$ for every $i \in [0, d]$. This implies \begin{equation*}
        0=r_01+r_1\gamma_1+...+r_d\gamma_d=\frac{p_0}{q_0}+\gamma_1\frac{p_1}{q_1}+...+\gamma_d\frac{p_d}{q_d}
    \end{equation*}
    Which can be reworked a bit as: \begin{equation*}
        \frac{p_0}{q_0}+\gamma_1\frac{p_1}{q_1}+...+\gamma_d\frac{p_d}{q_d}=\frac{\sum_{i=0}^{d}p_i\gamma_i\prod_{j\in[0, d]\setminus\{i\}}q_j}{\prod_{n=0}^{d}q_n}
    \end{equation*}
    this means, though, since by concatenating the equalities we can say that the aforementioned sum is equal to 0, that there indeed exists an integer vector that satisfies the defining condition, namely $(r_0,...,r_d), r_i=p_i\prod_{j\in[0, d]\setminus\{i\}}q_j$, which contradicts the hypothesis.
    
    The only part left to prove is that $(r_0,...,r_d), r_i=p_i\prod_{j\in[0, d]\setminus\{i\}}q_j$ is non-zero, because the absurd only leads us to the existence of an integer vector. This is trivial because the starting vector $(r_0,...,r_d)$ was non-zero, so at least one $p_i$ is non-zero itself. Multiplying it with $\prod_{j\in[0, d]\setminus\{i\}}q_j$ cannot make it zero because all of $q_j$s are non-zero by hypothesis.

    Now, we must prove $\underset{2}{\iff}$.

    $\Rightarrow$ is done by contradiction. RAA if there existed some combination of $k_d$s such that $\sum_{i=1}^{d}k_i=\rho\in\mathbb{Z}$, then the vector $(-\rho, r_1, ..., r_d)$ would contradict the hypothesis:
    \begin{equation*}
        -\rho+\sum_{i=1}^{d}=0
    \end{equation*}

    $\Leftarrow$ is actually the same thing, because you may notice that the steps of the last proof where all if and only ifs. So you may prove it by just changing the assumptions.
\end{proof}

\begin{proposition}
    $T_{\gamma}$ is topologically transitive $\iff$ the vector that defines it $(1,\gamma_1,..,\gamma_d)$ is rationally independent.
\end{proposition}

\begin{proof}
    The proposition we will actually prove is the following: \begin{equation*}
        T_{\gamma} \text{topologically transitive }\iff \nexists (k_1,..,k_d)\neq \vec{0}\text{ such that }\sum_{i}k_i\gamma_i\in\mathbb{Z}
    \end{equation*}
    which, in light of the precedent propositions, is the exact same as the one we are trying to prove. 

    $\Rightarrow$ is proven by contradiction. RAA Let's assume that such a vector $k=(k_1,...,k_d)\neq0$, for which $\sum_ik_i\gamma_i=<k,\gamma>=p\in\mathbb{Z}$, actually exists. Then, we may take the following function: \begin{equation*}
        f(x)=e^{2i\pi<k, x>}
    \end{equation*}
    We must observe that said function is defined on the torus, because of Euler's formula. $f(x)$ is also continuous and non-constant. This means that if we are able to show that it is also T-invariant we have completed the proof, since $T_{\gamma}$ cannot be topologically transitive if there exists such a function. We shall start by observing that:
    \begin{equation*}
        f(T_{\gamma}(x))=e^{2i\pi<k, x+\gamma \mod \mathbb{Z}^d>}e^{2i\pi<k, x+\gamma>}
    \end{equation*}
    We are able to lose the $\mod \mathbb{Z}^d$ since it is akin as subtracting an integer to the exponent which, again because of Euler's formula, is the equivalent to multiplying the whole thing by 1.

    After having done that, we may substitute with $p\in\mathbb{Z}$ and use the same property: \begin{equation*}
        f(T_{\gamma}(x))=e^{2i\pi<k, x+\gamma>}=e^{2i\pi<k, x>}e^{2i\pi<k, \gamma>}=f(x)
    \end{equation*}
    So, said f(x) is also T-invariant, which is absurd.

    We must now prove $\Leftarrow$.

    RAA Since by hypothesis T is a homeomorphism, we are proving this by contradiction by using the lemma. We start by assuming that T is not topologically transitive, which implies there exist $U\neq\emptyset$ open, $\neq M$ and T-invariant\footnote{Actually, we are guaranteed two of those, but we will only need one.}.
    
    So, $f=1_U$ is T-invariant too, and it is not identically equal to $1_M$. At this point, we may also verify that $f\in L^2(T^d)$, L2 meaning square integrable: this is due to the fact that it is limited in a limited space. 
    
    We can then employ Fourier's representation: \begin{equation*}
    f(x)=\sum_{k\in\mathbb{Z}^d}\hat{f}_ke^{2i\pi<k, x>}
    \end{equation*}
    If we do the same thing to $f\circ T$ we find:
    \begin{equation*}
        (f\circ T)(x)=f(T(x))=\sum_{k\in\mathbb{Z}^d}\hat{f}_ke^{2i\pi<k, x+\gamma>}=\sum_{k\in\mathbb{Z}^d}\hat{f}_ke^{2i\pi<k, x>}e^{2i\pi<k, \gamma>}
    \end{equation*}
    Which means that $\hat{f}_ke^{2i\pi<k, \gamma>}$ is the Fourier basis of $f\circ T$. We must consider, though, that f has been established to be T-invariant (and Fourier is unique), so we should have $\hat{f}_ke^{2i\pi<k, \gamma>}=\hat{f}_k$. 

    This would be possible if $<k, \gamma>$ was, somehow, an integer, which is against the hypothesis. Another possibility is that $\hat{f}_k=0$. This, though, implies $f=\hat{f}_0$, a constant. Since f is an indicator function, this must mean that f is either 1 or 0, but both are impossible because they would imply a contradiction of the initial hypothesis: either $U=\emptyset$ or $U=M$.
\end{proof}

\begin{definition}
    Suppose you have a manifold M of dimension d, with a semi-flow $(\phi^t)_{t\in\mathbb{R}^+}$ on it. Suppose you have a sub-manifold $M_0$ of dimension d-1 and assume that\begin{itemize}
    \item For every x in M there exists a time $t^+(x)>0$ such that $\phi^{t^+}(x)\in M_0$, and that there exists some $t^{-}>0$ such that $\phi^{t-}(x)\cap M_0\neq \emptyset$ (consider that $phi^{t-}(x)$ is a set because of the definition). Also, there exists some $\delta(x)$ such that no times with the above properties are in $[-\delta, \delta]\setminus\{0\}$ (in other words, times must not converge to 0). Set $t_{M_0}(x)=inf\{t>0|\phi^t(x)\in M_0\}\in(0,\infty)$: this is called hitting time to $M_0$, and if $x\in M_0$, return time. \footnote{Hw: realize that inf is a minimum};
    \item for every $U_0$ in $M_0$ open set in a topology of $M_0$ (induced by the topology of M), there exists some $\epsilon=\epsilon(U_0)>0$ such that $U=\cup_{0<t<\epsilon}\phi^{-t}U_0$ is open in M. This means that $U_0=A\cap M_0$ for some A open in M. (notice that we are defining being open in the cross-section);
    \item both $M$ and $M_0$ are "nice" spaces. 
\end{itemize}

In this case, $M_0$ is called a Poincarè section for the semi-flow $(\phi^t)_{t>0}$ and $T:M_0\rightarrow M_0$, defined $T(x)=\phi^{t_{M_0}(x)}$, is called the corresponding Poincarè map or first return map.
\end{definition}
